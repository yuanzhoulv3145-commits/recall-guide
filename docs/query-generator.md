# 听懂器

她说的那句话不直接拿去搜。先让一个小模型读这句话和前两句，只吐一个 JSON。

## 五个字段

```json
{
  "search": true,
  "topic": "米娅和阿澈上周去的那家火锅店",
  "keywords": ["火锅", "牛油锅底"],
  "image": false,
  "date": { "from": "2026-09-30", "to": "2026-09-30" }
}
```

| 字段 | 作用 | 规则 |
| --- | --- | --- |
| `search` | 闸门 | `false` 这一轮整个不翻 |
| `topic` | 语义榜的查询 | 8–40 字，把「那个 / 上次那个」换成具体内容，写清是谁的事；不写「记得 / 回忆」这类检索动词 |
| `keywords` | 关键词榜的查询 | 2–5 个原话或前文里**真出现过**的具体词，不编 |
| `image` | 找图 | 她在找以前发过的图片 |
| `date` | 日期窗口 | 她指了具体时间才填，按「今天」换算成日期；时间只进这里，不进 topic 和 keywords |

## 提示词（可直接改用）

```text
你是记忆检索的"听懂器"。米娅在和恋人阿澈聊天。读她这句话（结合前文），只输出一个 JSON：
{"search": true/false, "topic": "要找的具体事情（8-40字）", "keywords": ["2-5个具体词"], "image": true/false, "date": null 或 {"from": "YYYY-MM-DD", "to": "YYYY-MM-DD"}}
规则：
- 只有纯撒娇、寒暄、亲昵动作、语气词（如抱抱、晚安、哈哈哈、想你），且没有提到任何具体东西 → search=false。
- 提到具体的人名、地点、店、食物、身体状况、计划、约定、作品、经历、以前的某件事 → search=true。
- 出现"上次/还记得/说过/来着/之前" → 必须 search=true。
- topic 把"那个/上次那个/这个"按前文换成具体内容，写成"米娅…/阿澈…/两人…"并写清是谁的；提到某个人时，topic 写成"某某是谁、和米娅的关系或近况"。不要写"记得/回忆"这类检索动词。
- 亲密场景里的话按场景理解（如"不要停""走开"多是撒娇嘴硬），没有具体所指就不搜。
- keywords 只用原话或前文里真出现的具体词，不编。
- 她是在找以前发过的图片 → image=true。
- 她指了具体时间（昨天、前天、上周三、上个月、国庆、9月15号）→ 按"今天"换算成日期写进 date（一天就 from=to）；没指具体时间 → date=null。时间只写进 date，topic 和 keywords 里不再写时间词。
只输出 JSON。
```

用户消息里给三样东西：

```text
今天：2026-10-06 星期二
前文：阿澈：今天降温了 / 米娅：我知道
她现在说：上周三那家火锅店叫啥来着
```

**一定要带上星期几。** 没有它，模型算不对「上周三」。

## 代码兜底

小模型会出错，这几件事用代码兜住：

1. **「还记得」类问题强制翻。** 用一条正则（`来着|记不记得|还记得|你忘了|之前说过|上次.{0,8}(什么|啥|哪|吗)` …）判断。模型说不翻也照翻；模型挂了就用她的原句当 topic。
2. **时间词从关键词里剔掉。** 即使提示词写了，模型还是会把「昨天」「9月15号」放进 keywords。有日期时，用一条时间词正则把它们过滤掉。
3. **日期要验。** 格式不对、`to < from`、在未来、早于一年前 → 当没有日期。
4. **关键词长度。** 少于 2 个字的丢掉（找图除外，见 [找](retrieval.md)）。

## 选模型

要的是**快**和**会输出 JSON**，不需要聪明。我们实测（同一批句子）：

| 类型 | 中位延迟 |
| --- | --- |
| 托管推理平台上的 20–30B 级开源模型，关掉推理 | 0.2–0.3 s |
| 通用大模型 API（默认会先思考） | 1–3 s，且容易超时 |

两个模型轮换：第一个返回 429 就立刻换第二个。免费额度通常按模型分别计数，这样能撑过高峰。

## 实测例子（虚构句子）

| 她说 | 输出要点 |
| --- | --- |
| 昨天那家火锅店叫啥来着 | `search:true`，`date` = 昨天，keywords 只剩「火锅店」 |
| 上周三你说要给我讲的故事呢 | `date` = 上周三的具体日期 |
| 你还记得我的忌口吗 | `search:true`，`date:null`，keywords「忌口」 |
| 前天发的那张猫猫图 | `image:true`，`date` = 前天 |
| 老公抱抱 | `search:false` |
